# LUMÉ — шаблон лендинга для салона красоты

Одностраничный адаптивный сайт на чистых HTML, CSS и JS, без сборки и зависимостей.

## Структура
```
index.html
assets/
  css/style.css    — стили (цвета и шрифты в :root вверху файла)
  js/config.js     — ВСЯ информация клиента (редактировать только его)
  js/main.js       — анимации и логика
  images/          — картинки (замените на реальные фото)
```

## Как настроить под клиента (5 минут)
1. Откройте `assets/js/config.js`. Там есть название, контакты, часы работы, услуги и цены, мастера, отзывы, FAQ, сертификат и тексты.
2. Положите фото салона в `assets/images/` и укажите пути в config.js (`hero.image`, `about.image`, `team[].photo`, `services[].image`, `results.before/after`).
3. Цвета бренда задаются в `theme` в config.js (`accent`, `ink`, `paper`, `blush`).
4. Карта: в Яндекс Картах нажмите «Поделиться», затем «Виджет», скопируйте `src` и вставьте в `contacts.mapEmbed`.
5. Заявки задаются в `booking.mode`:
   - `whatsapp` — заявка с готовым текстом открывается в WhatsApp на номер `booking.whatsapp`;
   - `telegram` — открывается Telegram;
   - `endpoint` — JSON отправляется POST-запросом на ваш URL (CRM, Formspree, PHP-скрипт);
   - `demo` — показывается только окно «Заявка принята».

## Что внутри
- Интро-анимация, заголовок с меняющимися словами, арка-фото с параллаксом, вращающийся бейдж
- Бегущая строка, текст «О студии», который проявляется при скролле, счётчики
- Прайс с вкладками и превью-картинкой у курсора
- Слайдер «До / После»
- Шаги визита с прогресс-линией
- Мастера, карусель отзывов со свайпом
- 3D-сертификат с выбором суммы, FAQ-аккордеон
- Онлайн-запись: выбор услуги, мастера, даты и времени, маска телефона и валидация
- Cookie-баннер с настройками (необходимые, аналитика, маркетинг), выбор сохраняется
- Адаптив для экранов от 320px, мобильное меню и плавающая кнопка записи
- Учитывается настройка `prefers-reduced-motion`, разметка доступна для клавиатуры и экранных читалок

Подключение Яндекс Метрики после согласия на cookie: в `main.js` найдите функцию `cookies()`, место отмечено комментарием.
